
## Правила вызова утилиты analyzer, формат её командной строки и приёмы её использования.

#1. Командная строка утилиты analizer.

    analyzer [--ts-path | -t <TreeSitterPath>] [--ts-config_path | -c <TreeSitterConfigPath>] [--file-path | -p <FilePathPrefix>] (--file | -f) <File> [<File> ...]

    <TreeSitterPath> - полное имя исполняемого файла программы tree-sitter, вызываемой из analyzer для её внутренних нужд.
    <TreeSitterConfigPath> - полное имя файла конфигурации программы tree-sitter, которая будет передаваться tree-sitter'у при вызове.
    <FilePathPrefix> - общий префикс путей всех обрабатываемых файлов <File>.
    <File>... - перечисление (набор) целевых файлов, которые будут обработаны анализатором. Указание хотя бы одного такого файла обязательно.

    Для получения краткой помощи по формату командной строки программы её можно вызвать так:

    analyzer [--help | -h]

    Наличие в командной строке параметра "--help" выводит на консоль сжатое описание формата вызова утилиты. Все прочие параметры (если они указаны в командной строке)
при этом игнорируются.

#2. Описание назначения отдельных параметров командной строки и настройки среды окружения утилиты analyzer.

    Утилиты analyzer не является полностью автономной и использует в процессе своей работы внешнюю программы tree-sitter, а также файл её конфигурации. ППоэтому для своей правильной
работы она нуждается в информации о местоположении этих двух объектов, которые должны существовать, быть работоспособны и корректно составлены.

    Полное имя исполняемого файла программы tree-sitter может быть передано утилите через параметр командной строки --ts-path, посредством переменной окружения "TREE-SITTER",
а также этот модуль может быть найден утилитой самостоятельно, если он имеет определенное имя (tree-sitter.exe для Windows и tree-sitter для прочих платформ) и доступен через PATH.
Параметр командной строки, если он указан, имеет высший приоритет, при его неверном содержимом работа программы прекращается. Прочие два варианта используются, если параметр --ts-path
отсутствует.

    Полное имя конфигурационного файла можно указать посредством параметра --ts-config_path или переменной окружения "TREE-SITTER-CFG". Параметр командной строки также имеет преимущество,
при его некорректном содержимом работы программы завершается ошибкой.

    Если все обрабатываемые файлы расположены в одном каталоге (или его подкаталогах), пути к ним можно упростить указанием аргумента <FilePathPrefix> параметра --file-path. При наличии
этот префикс будет автоматически приставляться ко всякому имени <File> файлов-целей из списка аргументов параметра --file. Если все целевые файлы расположены там же, где и исполняемый файл
данной программы analyzer, можно использовать следующий формат параметра --file-path:

        --file-path $$$_EXE

    Если же все целевые файлы размещены в одном каталоге с tree-sitter[.exe], то можно применить такой макрос:

        --file-path $$$_TREE_SITTER

    При отсутствии параметра --file-path имена <File> должны быть полными или заданы относительно текущего каталога файловой системы.

    Самый простой способ обеспечить работоспособность программы - установка двух переменных среды окружения - "TREE-SITTER" с полным именем исполняемого файла tree-sitter[.exe] и
"TREE-SITTER-CFG" с полным именем конфигурационного файла. Его можно также разместить в одном каталоге с tree-sitter[.exe]. Там он будет найден автоматически.

#3. Модульные тесты.

    Модульные тесты также нуждаются в той же базовой информации, что и основная программа - маршрут исполняемого файла программы tree-sitter и её конфигурационного файла.
Так как модульные тесты не предполагают наличия командной строки, то наиболее простым и надёжным методом обеспечения их работоспособности будет создание те же двух переменных среды
окружения - "TREE-SITTER" и "TREE-SITTER-CFG". Существуют также и некоторые автоматические способы их поиска, но они сейчас ненадёжны и описываться здесь не будут. Эти переменные
должны содержать полные квалифицированные имена исполняемого файла программы tree-sitter и её конфигурационного файла (обычно он имеет имя "config.json") соответственно.
